Acerca del Proyecto

Sistema de Inventario de Vehículos

Aplicación web desarrollada con HTML5, CSS3 y JavaScript puro. Sin backend ni base de datos, almacenando toda la información en el navegador.

Características Principales

  • CRUD completo para gestión de vehículos
  • Dashboard con estadísticas en tiempo real
  • Almacenamiento persistente con LocalStorage
  • Información temporal con SessionStorage
  • Consumo de APIs REST públicas
  • Geolocalización del navegador
  • Web Workers para procesamiento paralelo
  • Validaciones completas de formularios
  • Búsqueda y filtrado de vehículos
  • Diseño responsivo

Tecnologías Utilizadas

Frontend:
- HTML5 (Estructura semántica)
- CSS3 (Diseño responsivo)
- JavaScript (Lógica de negocio)

APIs y Servicios:
- REST Countries API
- Geolocation API
- LocalStorage API
- SessionStorage API
- Web Workers API

Funcionalidades del Código

Validaciones:
- Campos no vacíos
- Año válido
- Precio mayor que cero
- Placas únicas

Procesamiento:
- Manejo de errores con try/catch
- Manipulación del DOM
- Eventos JavaScript
- Comunicación con Web Worker

Almacenamiento de Datos

LocalStorage:
Todos los vehículos registrados se guardan permanentemente.

SessionStorage:
- Última visita del usuario
- Nombre del usuario
- Email del usuario
- Última búsqueda realizada
