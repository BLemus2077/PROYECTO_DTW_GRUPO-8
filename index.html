Acerca del Proyecto

Sistema de Inventario de Vehículos

Aplicación web desarrollada con HTML5, CSS3 y JavaScript puro. Sin backend ni base de datos; toda la información se almacena en el navegador del usuario.

Características Principales

  • CRUD completo para gestión de vehículos
  • Registro de ubicación por departamento (El Salvador)
  • Dashboard con estadísticas en tiempo real
  • Almacenamiento persistente con LocalStorage
  • Información temporal con SessionStorage
  • Consumo de API REST (Open-Meteo)
  • Geolocalización del navegador
  • Web Workers para procesamiento paralelo
  • Validaciones completas de formularios
  • Búsqueda y filtrado de vehículos
  • Diseño responsivo

Tecnologías Utilizadas

Frontend:
- HTML5 (Estructura semántica)
- CSS3 (Diseño responsivo)
- JavaScript ES6+ (Lógica de negocio)

APIs y Servicios:
- Open-Meteo API (clima, JSON)
- Geolocation API
- LocalStorage API
- SessionStorage API
- Web Workers API
- Chart.js (gráficos)

Funcionalidades del Código

Validaciones:
- Campos no vacíos
- Año válido
- Precio mayor que cero
- Placas únicas
- Departamento requerido

Procesamiento:
- Manejo de errores con try/catch
- Manipulación del DOM
- Eventos JavaScript
- Comunicación con Web Worker

Almacenamiento de Datos

LocalStorage:
Todos los vehículos registrados se guardan permanentemente.

SessionStorage:
- Última visita del usuario
- Nombre del usuario
- Email del usuario
- Última búsqueda realizada
